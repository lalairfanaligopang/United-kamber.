Offline Backup / Device Transfer

Your data stays on this phone. Use Export to create a backup file. On another phone, open this app and Import that file. This transfers the complete player, match and ball-by-ball database without internet.

Cloud / Multi-phone note

The scoring engine is offline-first. Automatic cloud synchronization between phones requires a real hosted database and club login credentials. This package does not pretend to provide cloud sync without that backend.
